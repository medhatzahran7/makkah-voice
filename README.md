# صفحة الصوت — نظام مجوهرات مكة

صفحة التقاط صوت خارجية لنظام مجوهرات مكة (Google Apps Script).

## لماذا صفحة خارجية؟

تطبيق Apps Script يعمل داخل iframe معزول (sandboxed) يمنع المتصفح فيه الوصول
للميكروفون حتى مع سماح المستخدم. هذه الصفحة تُستضاف على نطاق عادي (GitHub Pages)
فتعمل فيها Web Speech API، وتعيد النص المنطوق إلى التطبيق عبر `postMessage`.

## التشغيل

يفتحها النظام عبر `window.open` مع:

- `?target=` — `analyst` أو `command` أو `podcast` أو `test`
- `?nonce=` — رمز جلسة يولّده التطبيق، والصفحة تردّده كما هو
- `?autostart=1` — بدء الاستماع تلقائياً (اختياري)
- `?autoclose=1` — إغلاق الصفحة بعد إرسال النص (اختياري)

## الأمان

الصفحة لا تحتوي على أي أسرار أو مفاتيح. التحقق يتم من جهة التطبيق: يقبل فقط
الرسائل الواردة من origin هذه الصفحة والتي تحمل الـ nonce الحالي للجلسة.

## الملفات

- `index.html` — الصفحة كاملة (ملف واحد، بلا موارد خارجية)
