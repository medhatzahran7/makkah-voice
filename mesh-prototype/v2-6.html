٦) الذكاء الاصطناعي — ترجمة وتنقية صوت 🤖

الترجمة تتم محلياً على جهاز المتكلم من صوته مباشرة، وتُبعت مشفرة مع الصوت — الوسيط لا يرى النص ولا الترجمة. الصوت الأصلي يصل أولاً، والترجمة تلحق به.

التنقية شغالة — تنقية عبر إعدادات المتصفح (إلغاء صدى + قمع ضوضاء + فلتر ترددات منخفضة). ليست RNNoise.

⏱️ الترجمة تضيف تأخير 2-4 ثوانٍ — الصوت الأصلي يصل أولاً، والترجمة تلحق به. الترجمة تعتمد على Web Speech API + MyMemory المجاني وتحتاج إنترنت. إن كان متصفحك لا يدعم التعرف على الكلام ستظهر رسالة واضحة ولن تتوقف المكالمة.

٨) شبكة أكبر — super-nodes + توجيه ذكي 🤖⭐

النقطة الثابتة: تليفون موصول بالشاحن وموجود دائماً (محل/بيت) — يُفضَّل كوسيط دائماً، فتثبت الشبكة حتى لو غابت باقي التليفونات.
⏳ أفضل مسار حالياً: — (ادخل الشبكة الأول)
📊 قياس المسارات سيظهر هنا: زمن الوصول + عدد القفزات + الاستقرار لكل مسار.

التوجيه الذكي: كل عقدة تقيس زمن الوصول وعدد القفزات والاستقرار لكل مسار متاح، وتختار الأسرع تلقائياً. وإذا سقط وسيط أثناء المكالمة، تعيد التوجيه تلقائياً لمسار بديل مع تنبيه "تم تحويل المسار".

🌉 بوابة بين المدن

البوابة: أي عقدة عندها إنترنت تنضم لغرفتين (مثلاً sayegh-mesh-1 للقاهرة وsayegh-mesh-2 للإسكندرية) وتربطهما — مكالمة من غرفة لأخرى تمر عبر البوابة مشفرة دون أن تُفك. مثال: غرفتك sayegh-mesh-1، والغرفة الثانية sayegh-mesh-2.

٩) وضع أوفلاين قريب — 📴 قادم لاحقاً

بصراحة كاملة: المتصفح لا يستطيع الوصول لـ WiFi Direct أو بلوتوث مباشرة — الوصول الحقيقي يحتاج تطبيق موبايل أصلي. في التطبيق الأصلي سيكون هذا WiFi Direct / بلوتوث تلقائياً بين تليفونين قريبين، من غير إنترنت خالص.

في هذا النموذج: التبادل اليدوي فقط كخطوة تمهيدية — أنشئ رمز اتصال وابعته للطرف الآخر، وهو يلصقه هنا:

⚠️ هذا القسم تمهيدي فقط: الرمز يثبت أن الطرفين يعرفان نفس الغرفة، لكن الاتصال الأوفلاين الكامل بلا إنترنت وبلا سيرفر يحتاج التطبيق الأصلي (WiFi Direct / بلوتوث) — وهو قادم لاحقاً.

التغطية الوهمية: حزم مشفرة وهمية بحجم ثابت كل ثانيتين، حتى لا يستطيع أي وسيط التمييز بين بدء مكالمة وعدم وجود شيء. سجل الوسيط لا يذكر مكالمة أبداً — فقط "تم تمرير حزمة مشفرة".

ابعت اللينك للتليفونين التانيين — هيفتحوا نفس الغرفة على طول. اللينك فيه ?room=... بس، من غير أي بيانات شخصية.

نموذج أولي v2.6 — لوحة تحكم المالك (مدن ← غرف ← قنوات + طرد + بوابات + إحصائيات) فوق v2.5 — رجوع تلقائي بعد الريفريش (جلسة محفوظة على جهازك فقط — بلا مفاتيح تشفير وبلا محتوى مكالمات) فوق v2.4 (شبكة أكبر (super-nodes + توجيه ذكي يقيس زمن الوصول والقفزات والاستقرار ويعيد التوجيه تلقائياً عند سقوط وسيط + بوابة بين المدن تربط غرفتين دون فك التشفير) + زر استغاثة SOS مشفر عبر الشبكة مع موقع ورابط خريطة، فوق v2.3 (ترجمة صوت+نص عربي↔إنجليزي وتنقية صوت، مكالمة خاصة من البداية، مكالمة مستمرة مفتوحة). لا سيرفر خاص، لا أسعار، لا أرقام تليفون. الإشارة عبر PeerJS المجاني، والتشفير WebCrypto فقط (ECDH P-256 + AES-GCM). التنقية عبر إعدادات المتصفح — وليست RNNoise. الترجمة عبر Web Speech API + MyMemory وتحتاج إنترنت، وقد لا تعمل على Safari/iOS. الوسيط يمرر حزماً مبهمة فقط ولا يفك ولا يعرف أن مكالمة بدأت. حدود صادقة: هوية الجار المباشر ظاهرة على مستوى اتصال PeerJS/WebRTC نفسه؛ الاستغاثة تصل عبر الشبكة فقط إذا وُجد مسار عقد متصلة — ليست بديلاً عن 112/النجدة عند عدم وجود أي عقدة قريبة؛ والوضع الأوفلاين القريب الحقيقي (WiFi Direct / بلوتوث بلا إنترنت) يحتاج تطبيق موبايل أصلي — المتصفح لا يستطيع الوصول لهما مباشرة، وهذا القسم في النموذج تمهيدي برمز يدوي فقط.
